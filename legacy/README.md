# Legacy launchers (replaced)

These are the previous per-process launchers (one Konsole per process, hard-coded
drone 11 / ports). They are kept for reference only and are not used by the new
apps. Use `scripts/dronelab.sh` (installed as the "DroneLab Flight" / "DroneLab Demo"
icons by `scripts/install-desktop.sh`) instead. Safe to delete once you are happy
with the new setup.
